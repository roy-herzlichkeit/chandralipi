## 1. `ingest/sun.py` (new, C13)
| function | exact behaviour |
|---|---|
| `lambert_shade(dtm, posting_m, azimuth_deg, elevation_deg)` | `gy, gx = np.gradient(dtm, posting_m)` with rows increasing **southward** (image-down) and columns eastward; slope `s = arctan(hypot(gx, gy))`; aspect `a = arctan2(−gx, gy)` measured clockwise from image-up; sun vector from `azimuth_deg` (clockwise from image-up) and `elevation_deg`; `shade = clip(sin(el)·cos(s) + cos(el)·sin(s)·cos(az − a), 0, 1)`; NaN where `dtm` is NaN; float32. No cast shadows (that is P1B.01). |
| `fit_sun_azimuth(dtm, posting_m, image, elevation_deg, *, valid=None, step_deg=1.0)` | `azimuths = np.arange(0, 360, step_deg)`; for each, `ncc = corr(lambert_shade(...)[m], image[m])` over `m = valid & finite(dtm) & finite(image)`; peak = argmax; `second_peak` = highest NCC at azimuths ≥ 20° (circular distance) from the peak; `peak_margin = ncc_peak − second_peak_ncc`; `n_valid_px = m.sum()`. `image` and `dtm` must have identical shapes (ValueError otherwise). |
| `sun_from_ode_metadata(json_path, product_name)` | load the ODE JSON; records at `doc["ODEResults"]["Products"]["Product"]` (a dict when there is one record — same parsing as `scripts/fetch_catalogue.query_ode`); pick the record whose `Product_name` upper-cased starts with `product_name` upper-cased; `elevation = 90 − float(Incidence_angle)`, `elevation_source = DOCUMENTED`; `azimuth = None`, `azimuth_source = UNKNOWN`, `azimuth_frame = "grid_up_clockwise"`; `note` names the JSON path and record. No match → `SunGeometry(None, None, UNKNOWN, UNKNOWN, "grid_up_clockwise", note="no ODE record for <name>")`. |
| `sun_from_label(product)` | OHRC label fields `sun_azimuth_deg`, `sun_elevation_deg` (field map, VERIFIED present); both sources `DOCUMENTED`; `azimuth_frame = "label_unverified"` (ISRO's azimuth reference direction is not documented in any file we hold); missing field → None + UNKNOWN. |
| `azimuth_elevation_from_vector(sun_body_xyz, lat_deg, lon_deg)` | pure geometry, no SPICE: `u = (cosφ cosλ, cosφ sinλ, sinφ)`, `e = (−sinλ, cosλ, 0)`, `n = (−sinφ cosλ, −sinφ sinλ, cosφ)`; `s` = input normalised; `elevation = degrees(asin(s·u))`; `azimuth = degrees(atan2(s·e, s·n)) mod 360` (clockwise from north). The input is the vector **from the surface point to the Sun** in body-fixed (IAU_MOON) coordinates. |
| `sun_from_spice(utc, lat_deg, lon_deg, kernels_dir)` | `import spiceypy` lazily (missing → `ImportError` naming the `spice` extra); `furnsh` `naif0012.tls`, `pck00011.tpc`, `de440s.bsp` from `kernels_dir` once per process (module-level set of loaded paths); `et = str2et(utc)`; `sun, _ = spkpos("SUN", et, "IAU_MOON", "LT+S", "MOON")` (km); surface point `p = 1737.4 · (cosφ cosλ, cosφ sinλ, sinφ)`; `azimuth_elevation_from_vector(sun − p, lat, lon)`; both sources `COMPUTED`, `azimuth_frame = "north_clockwise"`, `note` = kernel names + utc. |
| `north_to_grid_azimuth(az_north, lat_deg, lon_deg, proj4)` | converts to `grid_up_clockwise` numerically: project `(lat, lon)` and `(lat + 1e-4, lon)` with pyproj/rasterio to map x/y; `north_grid = degrees(atan2(dx, dy))` (clockwise from grid-up); returns `(az_north − north_grid) mod 360`. |
| `SunGeometry.as_tuple()` | `(azimuth, elevation)` when both are not None, else None. |
| `SunGeometry.as_dict()` | all fields; enum values as strings. |

## 2. `scripts/fit_reference_sun.py` (new; executed in P1.20)
CLI: `python scripts/fit_reference_sun.py [--nac 1|2] [--half-size-m 3000] [--kernels data/raw/reference/spice] [--out data/processed/vikram/reference_sun] [--label-convention]`.
1. **SPICE (primary, G14):** time and point of the NAC source frame from the ODE box JSON (`data/raw/reference/lro_nac_vikram/ode/edrnac4_vikram_box.json`, record `M1442997156LE` or `M1443025251LE` for `--nac 2`): `UTC_start_time` and the record's centre latitude/longitude fields as ODE names them in that JSON (read the file; do not assume names — if the centre fields cannot be identified, use the Vikram site point lat −69.37, lon 32.32 and say so in `note`). `sun = sun_from_spice(utc, lat, lon, kernels)`. Missing kernels, spiceypy or ODE JSON → exit 2 printing exactly what is missing and the command that provides it (`scripts/fetch_public.py --only spice_lsk,spice_pck,spice_de440s,ode_edrnac4_box`; `pip install -e ".[spice]"`).
2. **Cross-check A (ODE):** `sun_from_ode_metadata(...)` elevation vs SPICE elevation → `ode_elevation_deg`, `elevation_diff_deg`.
3. **Cross-check B (DTM fit):** DTM `data/raw/reference/lro_nac_vikram/NAC_DTM_VIKRAMSITE1.TIF` (own metric transform, same projection as the NAC: origin −11046, 638262, 3 m, measured 2026-09-29) and the NAC ortho window (square of `2·half_size_m` centred on lat −69.37, lon 32.32, located with `GeoReference.lonlat_to_pixel(lon=…, lat=…)`, read as a window only), reprojected onto the DTM grid (`rasterio.warp.reproject`, bilinear); `fit = fit_sun_azimuth(dtm_win, 3.0, nac_on_dtm, sun.elevation_deg, valid=nac > 0)`; convert SPICE azimuth to the grid frame with `north_to_grid_azimuth` and record `fit_minus_spice_deg` (circular signed).
4. **`--label-convention`:** for each OHRC label found by `ingest.catalog.build_catalog` (raw and calibrated), mid-time = mean of the label's start/stop times, point = mean of its four corners; `spice = sun_from_spice(...)`; compare with `sun_from_label(product)`: for each of the four conventions of `Phase_1B` (`as_is: a`, `plus_180: a+180`, `mirror: 360−a`, `mirror_plus_180: 180−a`) the circular difference to the SPICE azimuth. Write `label_convention.json` = `{"per_strip": [{tag, label_azimuth, label_elevation, spice_azimuth, spice_elevation, diffs: {convention: deg}}], "convention": <the convention with the smallest max diff over strips>, "max_diff_deg": float, "elevation_max_diff_deg": float, "source": "computed"}`.
5. Outputs under `--out`: `reference_sun.json` = `{"sun": sun.as_dict(), "cross_checks": {"ode_elevation_deg", "elevation_diff_deg", "dtm_fit": {azimuth_grid_deg, ncc_peak, second_peak_deg, second_peak_ncc, peak_margin, n_valid_px, step_deg, fit_minus_spice_deg}}, "inputs": {...paths...}}`, `ncc_curve.csv` (`azimuth_deg,ncc`), `label_convention.json` (step 4), and `run_record.json` (C15). Prints a summary.
